## Featured projects

**[Pondora](https://github.com/noura-st/pondora)** · Android · Kotlin
An app for practising social-anxiety exposure. The user completes a graded daily
task and rates their anxiety before and after, on a 1–10 scale. The app plots the
two lines against each other — turning "it wasn't as bad as I feared" into numbers.
`MVVM` · `Room` · `Retrofit` · `Coroutines/Flow` · `WorkManager` · `Lottie`

**[Melanoma Detection](https://github.com/noura-st/melanoma-detection)** · Python
Melanoma vs. benign classification on HAM10000. A from-scratch CNN compared against
eight classical ML pipelines. The point the README argues: the model with 91%
accuracy was missing 69% of melanomas — on imbalanced data, accuracy is the wrong
metric.
`TensorFlow/Keras` · `scikit-learn` · `Flask` · imbalanced data · ROC/AUC

**[Film & Kitap Öneri Sistemi](https://github.com/noura-st/Film-Kitap-Oneri-Sistemi)** · C#
Windows Forms over SQL Server; recommends films and books from your own ratings.
I reopened it a year later, found the passwords were stored in plain text and the
project no longer compiled, and rewrote both — PBKDF2 hashing, one connection string,
transactional saves, 13 tests.

**[NourArt](https://github.com/noura-st/NourArt)** · HTML/CSS
A Turkish art-learning site: landing page, course catalogue, a step-by-step drawing
tutorial, login and register screens. Zero JavaScript — the auto-scrolling slider,
the dropdown and the hover effects are pure CSS.
